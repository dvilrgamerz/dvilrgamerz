# ⚡ Dvilr Speed

A polished browser-based internet speed test inspired by modern speed-test dashboards.

## Features
- Download and upload measurement
- Ping measurement
- Animated speed gauge
- Connection detection
- Recent test history stored locally
- Responsive mobile/desktop UI
- No login required

> Browser-based speed measurements vary by device, browser, server distance, Wi‑Fi conditions, and network load. This is not an official Ookla Speedtest clone.

## Deploy
This folder is a static web app and can be deployed from GitHub to Netlify.
